# 分集大纲 / 场景大纲模板

> 每场 = 场景标题 + 3-5 句中文描述。不写对白，只写发生了什么、谁在场、价值如何变化。

---

# 第一幕 — 建立

## 第1场. 内景/外景. 地点 - 时间
[3-5句中文描述：发生什么、谁在场、场景价值从什么变成什么。]

## 第2场. 内景/外景. 地点 - 时间
[描述。]

## 第3场. 激励事件 — [地点]
[把主角从平衡中打出去的事件。通常发生在全片 22-25% 之前。]

---

# 第二幕 — 对抗

## 第N场. ...

> 复杂度递进：下一场必须比上一场更难。主角期待和实际结果之间的落差不断扩大。

## 第N+1场. 中点
[中段转折。通常是一次重大胜利或失败，之后赌注翻倍。]

---

# 第三幕 — 解决

## 第N场. 危机 — [地点]
[主角最终两难。必须在两个无法兼得的价值之间选择。]

## 第N+1场. 高潮 — [地点]
[回答两难的行动。全片最外化、最具体、最不可撤回的一刻。]

## 第N+2场. 余波 — [地点]
[新世界坐标。1-2场短戏。]

---

# 彩蛋（可选）

## 第N场. ...
[片尾后的场景：续集钩子或最终反转。]

---

## 大纲检查原则

填完后，逐场回答：

1. **每场是否能用“因为”接上上一场？**（第N场发生，是因为第N-1场发生了X。）
2. **每场是否推动价值变化**：从正到负，或从负到正？
3. **每场是否服务于作品的控制思想？**
4. **如果删掉这一场，故事结局会变吗？** 如果不会，这场可能多余。

如果有一个答案是否定的，这场就要重写或删除。

---

## 审阅标签

发现问题时标记：

- ⚠ **[ПРИЧИННОСТЬ]** — сцена не следует из предыдущей
- ⚠ **[ЦЕННОСТЬ]** — нет движения значения
- ⚠ **[БИБЛИЯ]** — конфликт с библией героя или мира
- ⚠ **[ТЕМП]** — слишком быстро / медленно для своей функции
- ⚠ **[INFO DUMP]** — экспозиция через диалог
- ⚠ **[ПОВТОР]** — повторяет то, что уже было
