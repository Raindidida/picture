# 《兔烟》第一集：五百円

## 项目信息

- 类型：青春叛逆 / 暴走族 / 异变惊悚
- 背景：1981 年，日本神奈川县，京滨走廊、大黑埠头、黄金町
- 主角：浅野拓海，18 岁，未入会的街头混混 / 加油站夜班小工
- 核心四人：拓海、片桐莲、黑泽刚、宫下良平
- 时长目标：约 2-3 分钟
- 核心意象：发动机、特攻服、五百円、酒吧后门、厕所镜子、二楼酒吧、烟头、酒瓶

## 结构分析

价值进入 -> 退出：

拓海从“街头混混生活是自由”进入，退出时意识到“还没加入组织，就已经开始被总长驯服”。

角色缺陷：

拓海看穿父亲的顺从，却没看穿自己的顺从。他还不是组织成员，却已经在总长面前学会低头、递烟、收钱。

本集转折：

女人求救时，拓海被莲拦住，也被自己的恐惧拦住。厕所里北原出现时，他更没有出手。二楼酒吧里，黑泽用暴力替他“出气”，但那不是勇敢，只是另一种失控。

潜在 red flags：

- 女人不需要在第一集展开背景，她是拓海觉醒的触发器。
- 北原不能演成单纯色狼或小混混，他是“成年系统”的入口。
- 五百円不是钱，是羞辱，也是拓海第一次被明码标价。
- 黑泽刚的打架不能写成英雄救场。他不是替女人伸张正义，而是被暴力兴奋感点燃。
- 月兔烟和变异后移到第二集或第一集结尾彩蛋，不要抢走这个觉醒转折。

为什么这样写：

第一集先展示“反抗生活”的爽感和违法快感，再用酒吧后门把爽感打碎。厕所里拓海被总长驯服，二楼酒吧里黑泽把羞辱转成无差别暴力。四个人还没加入组织，已经被组织的规则和街头的兴奋牵着走。
