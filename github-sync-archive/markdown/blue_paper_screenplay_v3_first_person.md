# 《蓝色纸》V3 第一人称现实搏斗版

类型：第一人称惊悚 / 无限空间 / 现实搏斗  
时长：约 5-6 分钟  
形式：全篇沉浸式第一视角。镜头就是男主视线。禁止上帝视角、监控视角、超现实怪相。  

## 核心改动

- 全程第一人称画面。
- 阿姨不是幽灵，是一个矮小、特别壮、脸色灰白、眼袋很重、像中国农村老阿姨的清洁工。
- 恐怖来自她的体力、枪、冷静、近身压制。
- 循环不做视觉奇观，只做真实空间跳转：厕所出口通向下一个封闭房间。
- 男主多次尝试逃跑、求饶、反击，都被真实打斗和枪击终止。
- 最后男主抢到枪逃出厕所，却进入下一个房间，成为新的威胁者。

## 场景价值变化

| 场次 | 进入价值 | 退出价值 |
|---|---|---|
| 第一次选择蓝色 | 尴尬求助 | 被冷静处决 |
| 第一次逃跑 | 以为能靠速度逃出 | 被背后两枪打死 |
| 求饶 | 以为服软能活 | 阿姨毫不犹豫杀人 |
| 马桶盖反击 | 有了工具和主动性 | 阿姨有第二把枪，力量压制 |
| 快剪搏斗 | 试错升级 | 所有正面对抗都失败 |
| 选择红色 | 以为红色安全 | 喷火器惩罚 |
| 打碎灯偷袭 | 从绝望转为战术 | 第一次真正击倒阿姨 |
| 出口逃脱 | 以为离开厕所 | 进入下一个无限空间 |
| 结尾举枪 | 受害者 | 新的威胁者 |

## 拍摄提示

- 镜头始终是男主视线：跑动、摔倒、护脸、抓枪都用第一视角完成。
- 阿姨身材矮但压迫感强：肩宽、手粗、动作稳，近身时占满画面。
- 不要拍成鬼。她会喘气，会被砸倒，会流汗，会换枪。
- 枪声用消音闷响，不用夸张爆炸声。
- 重置只用黑场、水箱滴水、男主猛吸气，不用炫光。
- 无限空间只在结尾出现：厕所门后变成真实的书法房间，黑墙封死退路。
