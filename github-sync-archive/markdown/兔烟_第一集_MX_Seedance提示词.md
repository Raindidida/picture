# 《兔烟》第一集《夕阳和五百円》MX Seedance 提示词版

## MX 版使用说明

这一版按 MX Seedance 的直接生成习惯写：

- 每条 8-12 秒左右。
- 不塞太多剧情。
- 每条只抓一个动作核心。
- 语句更短，主体更明确。
- 少用复杂规则块，多写可见画面。
- 适合逐条生成，再剪辑拼接。

## 统一风格

```text
1981年日本神奈川，昭和末期暴走族青春片质感，16:9，24fps，电影写实，胶片颗粒，低饱和，高反差，霓虹、钠灯、夕阳和冷白荧光灯混合。人物是原创虚构角色，禁止生成真实明星脸。
```

## 角色固定描述

```text
浅野拓海：18岁日本暴走族少年，瘦削，摄政头，眼神冷，校服衬衫敞开，裤脚沾机油，外穿褪色翻领特攻服，骑本田CB400 FOUR。

神崎曜子：17岁日本女高中生，漂亮但不甜，校服外套整齐，里面是违规低胸上衣，坐姿端正，眼神冷，像好学生但带街头危险感。

片桐莲：瘦、漂亮、油滑，金色挑染，衬衫领口松开，手指很快，笑得市侩。

黑泽刚：短发，肩颈粗，眼睛兴奋，特攻服敞着，像随时要打架。

宫下良平：傻瘦高，动作笨，特攻服穿得像借来的。

北原：30岁左右地下总长，白西装，黑衬衫，金戒指，眼神凶横，手上有血，腰间有枪柄。
```

## 01 夕阳街头，曜子踢拓海

```text
1981年日本神奈川河边商店街，昭和末期胶片质感，夕阳斜射，铁道桥阴影压在街面。浅野拓海推着本田CB400 FOUR从修车铺后巷出来，校服衬衫敞开，裤脚沾机油，嘴里叼烟。街对面神崎曜子从夕阳里走来，校服外套整齐，里面是违规低胸上衣，鞋跟踩过水洼。拓海看愣，立刻转身要走，曜子走近，一脚踢在他屁股上，他差点撞到机车。镜头先远景建立，再侧向跟拍拓海，最后手持中近景捕捉踢屁股动作。现场音：远处电车、机车链条、鞋跟踩水、打火机。禁止字幕、水印、logo、过曝、假脸、手指畸形、现代车辆、现代手机。
```

## 02 自动贩卖机旁的警告

```text
夕阳后的河边自动贩卖机旁，冷白贩卖机灯和橙色夕阳混合。拓海和曜子并排坐着，拓海喝罐装咖啡，曜子喝牛奶，她坐姿很端正，眼神却很锋利。曜子看着拓海说：“最近别跟地下的人走太近。有人死了。”拓海皱眉，把烟咬在嘴角，回嘴：“假好学生别教我。”曜子低头把牛奶罐捏扁，说：“你说得像你有别的路。”镜头固定双人中景，切过肩近景，再低机位跟拍咖啡罐滚到曜子脚边。现场音：自动贩卖机电流、铁轨远声、罐子滚动。禁止字幕、水印、logo、过曝、假脸、现代手机。
```

## 03 第三京滨暴走

```text
夜晚第三京滨高架，冷蓝黑色调，车灯拉丝。四辆改装机车冲上高架，浅野拓海骑在最前面，特攻服在风里拍打。本田CB400 FOUR转速表冲过一万，拓海猛拧油门。一辆警车从匝道冲出，拓海不减速，从警车旁擦过去，后视镜撞碎。镜头低角度追车，插入转速表特写，再用车载跟拍完成擦车瞬间。旁白合声像学校广播：“我们要健康。我们要成绩。我们要升学。”现场音：发动机轰鸣、警笛、玻璃碎、风噪。禁止字幕、水印、现代车辆、现代路牌、假脸、肢体变形。
```

## 04 偷油


## 06 莲偷钱包



## 13 给总长点烟

```text
冷白厕所里，北原看见水池边的小刀，又看拓海，伸出沾血的手，只说：“烟。”拓海从胸口口袋掏出烟盒，手指发抖，烟盒磕在洗手池边，一根烟掉进水里。他又抽出一根，用打火机点，第一次没点着，第二次火苗亮起。拓海把烟递过去，北原不接，只张开嘴。拓海僵住，把点好的烟放进北原嘴里。北原吸一口，冷笑，用沾血的手拍拓海肩膀后离开。现场音：水流、打火机两次咔哒、吸烟声、湿手拍肩。禁止字幕、水印、假脸、手指畸形、镜中错位。
```
