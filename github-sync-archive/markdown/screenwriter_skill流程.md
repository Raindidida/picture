# Screenwriter 剧本 Skill 流程

## 这个 skill 做什么

用于中文电影、短剧、剧集和分集大纲创作。

它的核心不是写散文，而是把故事变成可拍、可剪、可迭代的剧本。

## 默认输出规则

1. 默认全部用中文。
2. 剧本正文使用中文 Hollywood 变体格式。
3. 场景标题格式：

```text
内景/外景. 地点 - 时间
```

4. 动作行只写镜头能拍到、现场能听到的内容。
5. 不写人物内心解释。
6. 不写小说化描写。
7. 每次只给一个版本，不一次给多个方案。

## 标准工作流程

### 1. 先读上下文

如果已有材料，先看：

- 梗概
- 人物设定
- 世界观
- 分集大纲
- 旧场景
- 参考视频或图片

在没有足够上下文前，不直接写完整场景。

### 2. 判断结构位置

写每场前先判断：

- 这场在第几幕？
- 这场的价值从什么变成什么？
- 角色的致命缺陷是什么？
- 这是转折场，还是铺垫场？
- 它是否推动下一场发生？

### 3. 写一版可拍剧本

输出格式：

```text
内景. 地点 - 夜

动作行。

人物名
对白。
```

动作尽量短。

对白尽量有角色声音。

情绪交给动作、停顿、物件和演员。

### 4. 给 3-5 行分析

场景后面说明：

- 价值进入 -> 退出
- 角色缺陷如何被触发
- 潜在问题
- 为什么这样写

### 5. 只问一个窄问题

如果需要继续迭代，不问泛泛的问题。

错误问法：

```text
你想怎么改？
```

更好的问法：

```text
下一版是让他更怂，还是更疯？
```

## 修改规则

用户要求改哪里，就只改哪里。

如果只改一句对白，不重写整场。

如果用户否定版本，只问一个具体问题，再给下一版。

## 时长控制流程

如果用户要求“做成 2 分钟”“压到 30 秒”“第一集 1 分钟”，需要按真实屏幕时间估算：

- 场景建立：3-5 秒
- 简单动作：1-2 秒
- 复杂动作：3-5 秒
- 大事件：5-10 秒
- 短对白：1-3 秒
- 长对白：6-10 秒
- 停顿和反应：2-5 秒

不能只靠“1 页 = 1 分钟”。

## 结构审查流程

检查每场是不是因果关系：

```text
第 2 场发生，是因为第 1 场发生了某件事。
```

如果只是：

```text
然后又发生了一件事。
```

说明结构松。

常见标记：

- [原因] 场景不由上一场推动
- [价值] 场景没有价值变化
- [人物] 行为不符合人物设定
- [节奏] 太拖或太快

## 给材料的最好方式

可以直接发：

```text
类型：
时长：
主角：
背景：
参考片：
这一集发生什么：
结尾钩子：
不想要什么：
```

也可以直接丢一段粗糙想法，让 skill 先整理成可拍剧情。

## 当前项目用法

你现在的方向是：

- 参考《猜火车》的青春叛逆结构
- 毒品改成烟
- 背景改成日本 90-2000 年暴走族
- 主角 17 岁
- 开篇使用镜前挑衅式假狠
- 变异参考蛇烟视觉
- 第一集控制在约 2 分钟
