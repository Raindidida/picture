# 《兔烟》三集剧情拓展：曜子相遇版

## 调整重点

这一版第一集开头先是“夕阳街头相遇”，随后接回洗脑旁白式违法蒙太奇。

主线仍然是：

```text
混混少年以为自己在反抗系统，却被兽化黑产和地下组织拖进另一套系统。
```

但入口改成女主神崎曜子。

她不再只是第二集才出现的白月光，而是在第一集开场就和拓海相遇，直接把“学校系统”和“混混系统”撞在一起。

---

# 第一集：《夕阳和五百円》

## 时长

约 3-4 分钟。

## 开场：夕阳相遇

```text
外景. 河边商店街 - 傍晚
```

夕阳斜射。

铁道桥下的影子压在街面上。

拓海推着本田 CB400 FOUR，从修车铺后巷出来。

他嘴里叼着烟，校服衬衫没扣好，裤脚沾机油。

街对面，神崎曜子从夕阳里走来。

她穿着校服外套。

里面不是学校规定的白衬衫，而是一件成熟、挑衅、明显不合校规的上衣。

她拎着书包。

鞋跟踩过水洼。

拓海看愣。

不是下流地看。

是第一次发现自己幻想里的“好学生外壳”，身上也有夜里的东西。

曜子看向他。

拓海立刻转身要走。

曜子走近。

一脚踢在他屁股上。

拓海差点撞到机车。

曜子
浅野拓海。

拓海回头。

拓海
你是神崎曜子。

曜子
你在班上不是天天盯着我吗？

拓海叼着烟，嘴硬。

拓海
谁盯你。

曜子伸手，把他嘴里的烟抽走。

她看了一眼烟头。

曜子
便宜货。

## 路边聊天

两人坐在路边自动贩卖机旁。

拓海喝罐装咖啡。

曜子喝牛奶。

她坐姿很规矩。

说话却像刀。

拓海听说她是学校的大姐头。

又以为她是成绩很好的那种干净学生。

实际上曜子的成绩烂得吓人。

只是她坐姿太规矩，校服太干净，说话太像审判别人，连拓海都被那层壳骗了。

他不信。

拓海
你这种人也混？

曜子
你这种人也上学？

拓海没接上。

曜子提醒他：

```text
曜子
最近别跟地下的人走太近。
有人死了。
不是打架死的。
是被清理掉的。
```

拓海误会她在教育自己。

他火起来。

拓海
假好学生别教我。

曜子看他。

拓海
你们这些看起来会考大学的人就知道安分。

曜子没有生气。

她只是把牛奶罐捏扁。

曜子
你说得像你有别的路。
```

拓海站起来。

他把罐装咖啡喝完，罐子丢进路边垃圾桶。

没进。

罐子滚到曜子脚边。

拓海跨上机车。

发动机响。

曜子看着他。

```text
曜子
最近真的会死人。
```

拓海没有回头。

```text
拓海
那就别死。
```

他骑车冲出夕阳。

## 洗脑旁白与违法蒙太奇

```text
外景. 第三京滨 - 夜
```

黑暗里，四辆改装机车冲上高架。

拓海骑在最前面。

本田 CB400 FOUR 的转速表冲过一万。

合声（旁白）
我们要健康。
我们要成绩。
我们要升学。
我们要每天睡四小时。

一辆警车从匝道冲出。

拓海没有减速。

他从警车旁擦过去。

后视镜撞碎。

切至：

```text
外景. 加油站 - 深夜
```

拓海穿夜班工装，给货车加油。

司机进店买烟。

拓海拔出油枪，把汽油灌进自己的机车油箱。

油溅到鞋面。

合声（旁白）
我们要校服干净。
我们要鞠躬标准。
我们要把名字写进正确的格子。

切至：

```text
外景. 黄金町小巷 - 夜
```

莲撞上醉客。

弯腰道歉。

手指从醉客口袋里夹出钱包。

钱包飞到拓海手里。

拓海抽出现金。

合声（旁白）
我们要家庭。
我们要朋友。
我们要一张没有人说真话的饭桌。

切至：

```text
外景. 港口仓库 - 夜
```

黑泽刚用酒瓶砸向一个工人。

良平抱着偷来的啤酒，从旁边跑过。

脚下一滑。

啤酒碎一地。

他坐在玻璃渣里笑。

合声（旁白）
我们要生活。
我们要未来。
我们要你说谢谢。

基调：

亢奋、肮脏、青春、违法、带一点滑稽。

隐藏危机：

他们以为自己在自由地乱跑。

但高架桥下，一辆黑色皇冠停着。

车窗后，有人拍下拓海的车牌。

主题由此带出：

```text
拓海骂学校系统，却不知道混混世界也在等着给他编号。
曜子看似属于学校系统，其实早就被政府和兽化世界编号。
```

## 酒吧羞辱事件

晚上，拓海和莲在 `MOON RABBIT` 外抽烟。

女人冲出来求救。

拓海想动。

莲抓住他。

```text
莲
你要对总长干嘛？
他是这片地下的总长。
讨好他，还能拿钱。
管她，能拿什么？
```

北原抓住女人头发，把她拖回去。

丢给拓海皱巴巴的五百円。

```text
北原
烟钱。
```

厕所里，拓海嘴硬。

北原进来，右手有血，腰间有枪。

他看出拓海不服。

```text
北原
烟。
```

拓海颤抖着点烟。

第一次没点着。

第二次点着。

北原不接，张嘴。

拓海把烟放进北原嘴里。

北原冷笑离开。

## 夜闯队长家

拓海回到巷口。

那张五百円还在口袋里。

他越想越气。

不是气北原。

是气自己接了钱，还给他点了烟。

他决定做一件“能证明自己不是孬种”的事。

他一个人去队长家偷东西。

```text
外景. 队长住宅 - 深夜
```

旧洋房。

窗帘很厚。

拓海翻墙进院。

没有兄弟。

没有莲算账。

没有黑泽打头阵。

只有他。

他展示平时小偷混混的能力：

- 用发夹开窗锁。
- 用胶带粘住门铃线路。
- 用鞋底垫住木地板会响的地方。
- 用打火机照路，不开灯。
- 用纸片夹住门缝，判断屋里有没有风动。

他以为队长不在家。

事实上，队长就在床边。

只是他是变色龙蜥蜴系。

皮肤和墙纸混在一起。

拓海完全没看见。

他只盯着床头柜。

那里放着一个黑色铁盒。

拓海慢慢伸手。

队长的眼睛在墙上睁开。

一只手从墙纸里伸出。

抓住拓海手腕。

拓海僵住。

队长皮肤变色，慢慢从墙上“剥”出来。

他不是人。

是蜥蜴。

拓海想喊，喊不出。

队长张嘴。

舌头伸长。

就在他要咬下去时，窗外有影子落下。

曜子出现。

校服。

书包。

像刚从补习班回来。

她抬头。

瞳孔变细。

猫化。

她救下拓海。

第一集结尾：

拓海躲在床边，看见曜子把蜥蜴队长按在墙上。

指甲划开鳞片。

曜子回头看他。

```text
曜子
我说过，别跟地下的人走太近。
```

切黑。

# 第二集：《从天台掉下来的猫》

## 时长

约 3 分钟。

## 第二天学校

拓海来学校。

他整晚没睡。

曜子坐在前排。

校服整齐。

头发整齐。

像什么都没发生。

拓海看着她的后颈。

昨晚那里曾经浮出猫一样的暗纹。

老师点名。

曜子答得完美。

拓海低声骂。

拓海
怪物还会背课文。

曜子没有回头。

粉笔头从前排飞来，砸中拓海额头。

## 学校角落事件

午休。

拓海躲到教学楼后面的角落小便。

他刚拉开裤链。

远处，楼顶有一个人影坠落。

是曜子。

她从天台掉下来。

拓海看见了。

太远。

太快。

他不知道怎么办。

他刚要冲过去接。

曜子在半空一个翻身。

像猫。

她落到拓海肩膀上。

重量砸下来。

拓海裤子被震掉半截。

他羞耻大叫。

```text
拓海
你有病啊！
```

曜子平稳站在他肩上。

她低头看他。

没有笑。

她从袖口里抽出一把小刀。

刀尖放进拓海嘴里。

拓海立刻闭嘴。

曜子
不准说。

拓海含着刀，点头。

曜子从他肩上跳下。

她整理裙摆。

拓海手忙脚乱提裤子。

曜子
昨晚的事。
今天的事。
都不准说。

拓海嘴里还抵着刀。

曜子
听懂就眨眼。

拓海眨眼。

曜子收刀。

她转身离开。

走了两步，停下。

曜子
还有。

拓海捂着裤腰。

曜子
你小便很慢。

拓海气得说不出话。

## 深夜女人惨叫

晚上。

拓海骑车经过一条无人街。

风很冷。

店全关着。

远处有女人痛苦的叫声。

声音从一栋废弃大楼里传出来。

拓海停下。

他想走。

又想起 `MOON RABBIT` 后门那个求救的女人。

他握紧车把。

这次，他没有立刻逃。

他下车，走进废楼。

第二集结尾：

楼道深处，门牌 `108`。

门缝下有血。

还有一只政府信封。

信封上写：

```text
清理对象：犬系。
执行人：神崎曜子。
```

切黑。

# 第三集：《108》

## 时长

约 4 分钟。

## 废楼真相

拓海推开 108 室的门。

里面不是鬼屋。

是曜子的房间。

折叠床。

小冰箱。

熨好的校服。

墙上贴着课程表。

桌上放着政府任务信封。

一个半兽化犬系男人被绑在地上。

还活着。

曜子站在旁边。

手上有血。

她看见拓海。

没有惊讶。

```text
曜子
你还是来了。
```

## 曜子的身份

曜子告诉他：

她住在这里。

家里不要她。

政府给她合法身份。

代价是清理危险违法动物人。

拓海不信。

曜子把信封丢给他。

里面是目标照片、现金、动物系判断。

拓海看见自己的学校也在名单附近。

说明兽化污染已经进了学校。

## 犬系目标失控

地上的犬系男人醒来。

绳子崩断。

他扑向拓海。

拓海吓住。

曜子猫化，挡住。

这一次，拓海没有只看。

他捡起地上的烟灰缸砸过去。

砸偏。

但打断了犬系男人的动作。

曜子抓住机会，解决目标。

拓海喘着气。

他第一次主动参与了怪物世界。

不是因为面子。

是因为他不想再站着看别人被拖走。

## 第三集结尾

曜子清理现场。

拓海看着她把血擦得过分干净。

他想说什么。

曜子先开口。

```text
曜子
别用那种眼神看我。
我不是你要救的好学生。

我成绩比你还烂。
```

拓海
我也不是好人。

曜子看他。

拓海把那张皱巴巴的五百円放在桌上。

拓海
但我不想再拿这种钱。

门外，楼道灯闪。

有人把新信封塞进门缝。

信封上只有两个字：

```text
月兔
```

曜子和拓海同时看向门。

切黑。
