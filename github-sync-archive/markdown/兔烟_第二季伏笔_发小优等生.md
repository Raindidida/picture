# 《兔烟》第二季伏笔：拓海的发小优等生

## 基础设定

- 姓名：森川千夏
- 年龄：17 岁
- 身份：拓海的发小 / 同校优等生 / 第二季主要登场人物
- 表层标签：成绩极好、纪律感强、说话温柔、老师信任、父母眼中的理想孩子
- 真实标签：一直喜欢拓海、比任何人都早看见拓海的裂缝、害怕自己被他的世界抛下

## 角色功能

千夏才是拓海身边真正的“好学生”。

她成绩稳定在年级前列。

她会整理笔记。

会替拓海留讲义。

会在他缺课后把作业夹进他的课桌。

也会在老师问起拓海时，冷静地替他撒一个不太漂亮但很管用的谎。

第一季里，她只作为背景存在：

- 教室前排空着一个整齐的座位。
- 拓海抽屉里偶尔多出一份干净讲义。
- 老师点名时，有人小声说“他身体不舒服”。
- 拓海没有看见是谁。

第二季，她正式进入故事。

她喜欢拓海，不是因为他像暴走族。

而是因为小时候的拓海曾经是第一个发现她哭了的人。

## 与曜子的对照

曜子看起来像好学生，成绩却特别差。

千夏是真正的优等生，却一直在替拓海做不合规的事。

曜子把拓海拉进怪物世界。

千夏让拓海想起：他原本也有机会留在白天。

这不是简单的三角恋。

这是两个女孩分别代表两种系统：

```text
曜子：被黑夜收编的人。
千夏：被白天规训的人。
拓海：以为自己逃出了系统，其实只是还没决定被哪一边吞掉。
```

## 第二季入场建议

第二季第一集，拓海从兽化事件后回到学校。

他的课桌里放着一叠补好的笔记。

最上面夹着一张便签：

```text
你再不来，老师就要去你家了。
我又帮你撒谎了。
这是最后一次。
森川
```

拓海看着便签。

他想不起上一次认真叫她名字是什么时候。

走廊尽头，森川千夏抱着课本看他。

她眼圈发红。

但她笑得很标准。

像一个满分答案。
