# 虎途养车广告微电影：《别人的车也不好坐》3分钟压缩版

类型：黑色幽默 / 灵魂互换 / 都市荒诞 / 亲情反转  
品牌：虎途养车  
男主身份：普通上班族，孩子爸爸  
男主车辆：比亚迪新能源家用车  
时长：约3分钟  

核心表达：前面不讲养车，只讲人和车里真实、尴尬、荒诞的问题。直到最后，男主才意识到：那些被他忽略的车况和生活一样，不会因为不看就不存在。

## 声线设定

### 男主陈屿

36岁，上班族，低中音，略哑。嘴上习惯道歉，心里很会吐槽。前半段羡慕别人，后半段开始安静。

### 旁白

45岁以上男性，低沉、干、慢半拍。像一个嘴损的熟人，专门替男主说出那些不体面的念头。

### 虎途员工

最后才出现。专业、自然，不推销。

## 灵魂互换规则

每次互换必须清楚：

1. 男主被一句话或一个场面刺痛。
2. 男主产生“我要是他/她就好了”的动机。
3. 男主看向对方眼睛。
4. “叮”一声互换。
5. 男主进入对方身体后，先身体不适应，再立刻执行刚才的欲望。
6. 原本的人进入男主身体后，仍保留原行为习惯、说话方式和关系认知，并继续按原关系跟男主互动。
7. 前段不说养车、不说服务，只让问题自然暴露：车内乱、车顶卡、车膜起泡、轮胎异响、启动慢、房车水电问题等。
8. 只有最后虎途门店段才出现养车服务内容。

> 他刚开始很不适应。高跟鞋像两根审判，香水像一份不许请假的合同。但坐进后排那一秒，他又觉得，权力这东西，真香。

父亲台词：
> “车也好，轮椅也好，都是腿。腿不管，人就走不远。”

结尾旁白：
> 他羡慕过敞篷、老板车和一人一狗的远方。最后发现，每辆车都有自己的毛病。自己的车也有。好在，自己的毛病可以自己修。

品牌口播：
> 虎途养车。别羡慕别人的车，先养好自己的车。
