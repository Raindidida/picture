# Seedance 细化提示词分类与反推规则

本参考用于把粗略剧情、参考图、参考视频、关键帧或首尾帧，反推成更细、更长、更稳定的 Seedance / 即梦提示词。目标不是文学描写，而是把画面、声音、运镜、风格、约束都写成模型可执行的视觉规则。

## 先分类，再写正文

每次生成前先判断提示词类型。常用三类如下：

1. 无场景图风格描述类型
   - 适用：用户只有剧情、角色图、道具图、色卡，没有完整场景图；或需要从文字搭建整个视频场面。
   - 核心：用 `STYLE LOCK`、`REFERENCE LOCK`、`场景物理设置`、`起手/中段/收手`、`声音设计`、`关键约束` 搭出完整视频。
   - 重点：方向、速度、空间关系、角色造型、材质、色卡、声音来源都要锁定。

2. 固定镜头 / 关键帧图像提示词类型
   - 适用：首帧、尾帧、封面帧、截图锚定、图像生成 prompt、需要固定构图的单帧。
   - 核心：用 `用途`、`STYLE LOCK`、`REFERENCE LOCK`、`镜头与机位`、`构图`、`光线`、`空间关系`、`约束` 规定单帧。
   - 重点：画幅、镜头焦段、机位高低、主体占比、前景/中景/背景、焦点、景深、清晰区、遮挡、姿态、不可出现元素。

3. 首尾帧 / 长镜头视频提示词类型
   - 适用：用户给首帧尾帧、要求“一镜到底”、从 A 姿态运动到 B 姿态、5-15 秒连续运镜。
   - 核心：先锁定起幅和收幅，再写中间动作链与镜头运动路径，最后写声音和尾帧动态保持。
   - 重点：起幅严格等于首帧、收幅严格等于尾帧；中间运镜必须一气呵成；不要切镜；尾帧不能冻结，要保留风、尘、衣料、光效等运动。

可扩展子类：

- 硬切蒙太奇：多个独立画面用 `HARD CUT` 串联，每段独立机位、独立环境声、独立光影。适合回忆、日常、训练、时间流逝。
- 多机位剧情分镜：每段有明确时间戳、景别、动作、对白、声音。适合对话、冲突、短剧。
- 参考视频复刻：先拆参考视频的节奏、运镜、动作、特效、声音，再替换主体。
- 画框转换 / 分屏对话：通过竖直分割线、水平分割线、画面压缩、替换区域，把两个空间并置。适合电话、远程问答、双线剧情和风格反差。
- 打斗 / 动作喜剧：把动作拆成起手、突变、失衡、碰撞、停顿、反应、收束。适合武侠、追逐、狼狈逃跑、被抓求饶、冷面执行。
- 遮挡调度：用前景物、道具、门框、桌面、玩偶、烟雾、衣料遮挡敏感动作或制造喜剧悬念。必须写清遮挡物位置、占比、清晰度和后景露出范围。

## 生成前 Plan 模板

```text
Plan：
1. 输入判断：[纯剧情 / 参考图 / 参考视频 / 首尾帧 / 关键帧 / 混合素材]
2. 提示词类型：[无场景图风格描述 / 固定镜头关键帧 / 首尾帧长镜头 / 硬切蒙太奇 / 多机位剧情]
3. 结构：[STYLE LOCK] + [REFERENCE LOCK] + [场景/空间规则] + [时间段画面] + [声音] + [关键约束]
4. 参考内容概括：@图片1 锁定[人物/道具/场景/色卡/构图]，可继承[具体元素]，不可改变[具体元素]。
5. 风格与运镜：引用[导演/摄影师/影片]的[可执行技术特点]，服务于[剧情目标]。
6. 贯穿锚点：[风/尘/水汽/霓虹色块/手持呼吸/底噪/遮挡物/分屏线/色卡/表演反差]从开头持续到结尾。
7. 目标对比：本条提示词的目标是[锁人物/锁场景/锁运动方向/锁首尾帧/锁对话节奏/锁遮挡/锁声音]，删除不服务目标的空泛词。
```

短提示词可以压缩 plan，但不能跳过类型判断。

## 目标对比与去废话规则

生成前先对比“用户目标”和“提示词内容”。每一句都要服务一个可验证目标，否则删除。

保留：

- 锁定身份：人物、服装、发型、道具、场景、色卡、音色、首帧、尾帧。
- 锁定运动：方向、速度、起点、过程、终点、谁追谁、谁看谁、谁挡住谁。
- 锁定摄影：机位、景别、焦段、固定/手持/拉远/硬切、构图占比。
- 锁定表演：眼神、呼吸、肩膀、手指、重心、台词语速和音量。
- 锁定声音：环境底噪、动作音、电话声、画外声、过场声、静默节拍。
- 锁定禁止项：字幕、水印、logo、错位风格、错误朝向、错误裸露、错误新增人物。

删除或压缩：

- “电影感、大片感、高级感、氛围感”这类没有具体摄影含义的词，除非后面跟了镜头、光线、色彩、材质。
- 重复的“真实、超清、精致、震撼”，只保留一次并转成可执行细节。
- 和目标无关的导演名堆叠。每条最多 1-2 个风格来源，且必须写技术特点。
- 不影响画面的心理解释。改写成可见动作、可听声音、可拍环境反馈。
- 过多负面词。只保留最容易生成错的 5-10 项，集中放在约束段。

目标对比模板：

```text
目标：[这条提示词最想稳定生成什么]
必须保留：[人物/场景/动作/声音/构图/首尾帧/遮挡/节奏]
应删除：[不服务目标的风格词、重复形容词、空泛品质词、无关镜头术语]
```

## 问答重构模式

当用户对初稿不满意，并要求“问答模式 / 你问我 / 逐项问 / 先别生成”时，先不要生成完整提示词。把已有提示词当作草稿，从模板类型反推缺失模块，按模块提问，等用户回答后再生成。

### 进入流程

1. 复盘已有提示词：
   - 已确定：人物、参考图、场景、时长、画幅、类型、台词、动作、声音、首尾帧。
   - 缺失：镜头、场景物理、特效目标、表演锁定、声音层级、遮挡/约束、色卡/光线。
   - 冲突：例如“一镜到底”又要求多次 HARD CUT；固定机位又要求环绕；无 BGM 又要求音乐卡点。

2. 选择问卷类型：
   - 无场景图风格描述：重点问场景物理、运动方向、速度关系、参考锁定、收手画面。
   - 固定镜头 / 关键帧：重点问镜头、构图、焦点、前景遮挡、主体占比、不可出现项。
   - 首尾帧 / 长镜头：重点问首帧、尾帧、中间转场机制、贯穿轴、尾帧动态保持。
   - 画框转换 / 分屏对话：重点问画框转换方式、左右空间风格、台词触发、声音归属、反应尾帧。
   - 打斗 / 动作喜剧：重点问动作关系、起手节拍、突变点、失衡/撞击、收束、声音切断。
   - 遮挡调度：重点问遮挡物是什么、放在哪里、占比多少、遮住什么、露出什么边缘。

3. 每轮只问 3-6 个问题。每个问题给选项，用户可直接回复选项编号，也可自由补充。

4. 用户回答后输出短暂确认：

```text
已确认：
- 镜头：[答案]
- 场景锚点：[答案]
- 特效目标：[答案]
还缺：[声音层级 / 约束 / 收尾画面]
```

5. 关键模块完整后再生成完整提示词。不要无限追问；如果用户说“够了，直接写”，用已确认信息和合理默认值生成。

### 通用问题库

#### 1. 这是一个什么镜头？

用于所有类型，先确定摄影机逻辑。

选项：

- A. 三脚架固定镜头：画面不运动，只让人物、光、尘、风、前景动。
- B. 真人手持长焦：画面有呼吸漂移、小修正、真实不稳定。
- C. 低机位跟拍：贴地或贴近主体，适合追逐、打斗、压迫。
- D. 顶拍 / 垂直俯拍：适合分屏、电话、几何构图、角色躺卧。
- E. 首尾帧连续转场：从首帧运动到尾帧，中间不切镜。

追问技巧：

- 如果用户选 A，继续问“画面里唯一运动的东西是什么？”
- 如果用户选 B，继续问“手持是紧张纪录片、慵懒生活感，还是长焦放大呼吸？”
- 如果用户选 E，继续问“首尾之间靠什么缝合：同一个道具、同一动作、同一颜色、同一声音？”

#### 2. 场景特点是什么？

用于把“房间/沙漠/天台”变成可生成空间。

选项：

- A. 空旷压迫：大留白、小人物、风声或低频底噪。
- B. 狭窄拥挤：前景遮挡、货架/桌面/门框压迫、浅景深。
- C. 霓虹混色：粉紫、冷蓝、暖橘、空气尘埃、光斑虚化。
- D. 自然外景：风、草、沙、雨、水汽、真实日光变化。
- E. 机械/废土：青铜、木甲板、磨损金属、沙尘、引擎或机械关节声。

必须追问：

- 场景里最重要的贯穿锚点是什么？
- 前景、中景、背景分别是什么？
- 哪个元素不能改变或不能丢失？

#### 3. 特效 / 转场目标是什么？

用于避免“特效很酷”这种空话。

选项：

- A. 消融重塑：草浪变天空、烟雾变房间、光斑变霓虹。
- B. 硬切反差：前段安静，JUMP CUT 后状态突变。
- C. 画框转换：竖线/横线移动，分屏或替换空间。
- D. 机械变形：外壳打开、肢体伸展、关节锁定、吞咽/闭合。
- E. 遮挡隐藏：前景物挡住关键动作，只露边缘。

追问：

- 特效从什么变成什么？
- 特效发生在哪个时间点？
- 特效结束后的尾帧必须是什么状态？

#### 4. 角色表演锁是什么？

用于让人物不漂。

选项：

- A. 死pan零反应：身体几乎不动，只眼神或头部极慢变化。
- B. 慌乱爆发：无预动作，突然弹起、摔倒、喘息、逃跑。
- C. 冷面执行：动作稳定，完全不被对方求饶影响。
- D. 慵懒摆烂：语速慢、尾音拖长、身体懒散。
- E. 克制震惊：动作突然停止，眼睛睁大，吸气，环境声下沉。

必须追问：

- 哪个角色负责反差？
- 表演变化发生在哪一秒？
- 台词语速、音量、口音或音色参考是什么？

#### 5. 动作目标是什么？

用于打斗、追逐、动作喜剧。

选项：

- A. 追逐压迫：谁追谁，谁在前，谁更快，是否超越。
- B. 近身交手：第一击、格挡、反击、失衡、收束。
- C. 狼狈逃跑：静止、惊叫、手脚并用、摔倒、爬起、远离。
- D. 冷面处置：抱起、搬走、送入机械/门/阴影，声音切断。
- E. 仪式动作：挥剑、转身、落定 pose，强调首尾姿态。

追问：

- 动作的起点、过程、终点分别是什么？
- 哪个瞬间是节奏爆点？
- 最后一帧停在胜负、静默、逃远、吞声，还是 pose？

#### 6. 声音层级是什么？

用于让声音像模板一样精确。

选项：

- A. 只有环境音和动作音，无 BGM。
- B. 电话 / 通讯声：一边现场声，一边压缩电话声。
- C. 极静默反差：前段无人物声，突变瞬间尖叫或撞击打破。
- D. 机械声音：铰链、关节、液压、金属闭合、吞咽低频。
- E. 空间切换声：画框转换 hum，旧底噪退，新底噪进。

追问：

- 哪个声音贯穿全段？
- 哪个声音必须突然切断？
- 台词是否需要 @音频锚定、口音、语速？

#### 7. 约束和禁区是什么？

用于减少生成错误。

选项：

- A. 禁止字幕、水印、logo、UI、文字。
- B. 禁止新增人物或路人。
- C. 禁止错误朝向、对冲、转向、静止主体。
- D. 禁止风格跑偏：卡通、CG、塑料、现代物件。
- E. 禁止露出被遮挡动作，只允许边缘轮廓。

追问：

- 最容易生成错的 3 件事是什么？
- 哪个参考图必须 100% 锁定？
- 哪个元素可以自由发挥？

## 画面描述维度

### 1. STYLE LOCK 风格锚定

描述技巧：

- 先写媒介质感：35mm 胶片、Kodak Vision3、ARRI Alexa、IMAX、anamorphic、photochemical look、胶片颗粒、halation。
- 再写美学方向：废土追逐、王家卫式生活混剪、维伦纽瓦式巨物压迫、黑色电影高反差、纪录片手持。
- 最后写负面风格：不是 3D 渲染、不是廉价游戏 CG、不是塑料材质、不是卡通、不是干净数字画面。
- 导演名字后必须跟技术特点，不能只堆名字。

可用写法：

```text
[STYLE LOCK] 35mm Kodak Vision3 胶片质感，analog film grain，实景摄影，钨丝灯与自然光混合，轻微高光晕染，真实旧物磨损；引用王家卫式手持生活片段、慢门拖影、浓郁红绿混色和硬切节奏，但保持剧情动作清晰；禁止廉价数字锐化、塑料皮肤、游戏 CG 感。
```

### 2. REFERENCE LOCK 参考锁定

描述技巧：

- 每个参考只承担一种清晰任务：人物、坐骑、武器、场景、色卡、首帧、尾帧、动作、运镜、声音。
- 参考图要写“可见外观 + 材质 + 色彩 + 不可改变项”。
- 人物参考不要重复臆造五官；写发型、服装、体态、标志物、表演气质。
- 色卡参考要说明所有色彩按色卡执行，不偏离。

可用写法：

```text
@图片1 作为主角造型视觉锚定：黑色短发、红绳发饰、黑红破败长外衣、长手套、冷淡寡言气质严格保持；不改发型、不改服装色、不新增饰品。
@图片2 作为场景环境锚定：崩塌部落沙丘、土褐崖壁、酒红破帐、漫天沙尘按此图延展。
@图片3 作为整段色卡锚定：暖沙土金、赭红、青铜绿、深黑阴影严格按色卡执行。
```

### 3. 场景物理设置

描述技巧：

- 写空间：地点、地形、方向、前中后景层次、主体相对位置。
- 写运动：谁在前、谁在后、朝哪个方向、速度关系、是否追平/超越/拉远。
- 写物理反馈：沙尘、衣料、金属震动、脚步、风压、烟雾、雨水、玻璃、光束尘埃。
- 动作场景要写“铁律”，避免模型误解方向或角色关系。

可用写法：

```text
【场景物理设置】所有大型移动物体朝画面深处同一方向运动，不存在对冲；主角船在最前方逃跑，两艘沙艇居中追击，机械坐骑从最后方加速追上并超越沙艇。所有车辆始终全速移动，船腿踏沙、沙艇尾部扬尘、坐骑机械蹄击打沙地，运动方向与沙尘拖尾一致。
```

### 4. 镜头与机位

描述技巧：

- 先写镜头：24mm 广角、50mm 标准、长焦、变形宽银幕、浅景深。
- 再写机位：贴地低机位、过肩、侧前方、中近景、极特写、俯拍、仰拍。
- 再写运动：推进、拉远、跟拍、环绕、甩动、移焦、硬切。
- 焦段变化必须平滑：从广角强透视过渡到标准镜头，或从特写拉开到中景。

导演/影片运镜引用：

- 王家卫：手持轻晃、慢门拖影、狭窄空间、霓虹/钨丝灯混色、硬切生活片段、浅景深人物特写。
- 乔治·米勒 / 《疯狂的麦克斯》：低机位高速追拍、同向运动、强透视、沙尘逆光、动作因果居中清楚。
- 杜可风：贴近人物、手持呼吸感、色彩浓烈、环境光包裹人物。
- 维伦纽瓦 / 《沙丘》：巨物压迫、低饱和沙土色、极简构图、宏大留白、慢速推进。
- 库布里克：对称构图、冷静固定机位、精确轴线、人物在秩序空间中被压迫。
- 斯皮尔伯格：阻挡调度、人物视线引导、从主观惊奇到环境揭示。
- 塔可夫斯基：长镜头、自然元素流动、水/火/风/尘、缓慢空间穿行。

### 5. 构图与主体占比

描述技巧：

- 写主体位于画面哪一侧、占多少相对面积、身体朝向、视线方向。
- 写前景遮挡、背景虚化、引导线、留白、对角线。
- 单帧关键帧要明确清晰区与焦外区。
- 不必大量写精确厘米和角度；优先用相对位置。但当参考文档要求焦段或画幅时可保留镜头数值。

可用写法：

```text
人物位于画面右侧三分之一，身体侧向画面深处，头肩占画面主导；前景有失焦麦穗斜切过画面，下方剑身高光是唯一清晰焦点，人物衣物和背景天空全部处于柔和焦外。
```

### 6. 光线、色彩、影调

描述技巧：

- 光源：夕阳逆光、窗侧光、霓虹混色、冷白荧光、顶光压迫、阴天柔光。
- 光行为：边光镶边、尘雾中形成光束、脸部半明半暗、金属高光、皮肤高光。
- 色彩：主色、辅色、点缀色、阴影色、饱和度、对比度。
- 影调要服务情绪：压抑用低照度与高反差；日常回忆用胶片暖色和硬切；追逐用逆光沙尘和高动态模糊。

### 7. 动作链与表演

描述技巧：

- 动作必须有起点、过程、终点。
- 人物情绪必须落到眼神、嘴角、下颌、呼吸、肩背、手指、步态。
- 动作和台词绑定：谁在什么动作中说哪句，声音是什么质地。
- 长镜头要写中间过渡，不只写首尾结果。

可用写法：

```text
她先低头看向布袋，眉毛短促上扬，嘴唇微张；随后猛地抬眼望向对面，眼睛越睁越大，呼吸停顿半拍，脱口而出：“你就是那个女道士？！”
```

### 8. 声音设计

描述技巧：

- 默认仅环境音、动作音、对白音，不加 BGM，除非用户明确需要。
- 声音随空间变化：远景低频、近景清晰、运动物体有多普勒变化。
- 硬切蒙太奇每一段声音也硬切，不能用同一氛围音糊住。
- 动作音要与画面同步：脚步、金属、衣料、风声、沙尘、雨水、玻璃、呼吸。

可用写法：

```text
音轨：仅环境音与动作音，不配 BGM。硬切到夜市时同步切入油锅爆响、人群喧腾和霓虹电流声；硬切到雨后山林时声音变为竹叶滴水、湿土脚步和远处鸟鸣。
```

### 9. 关键约束 / 铁律

描述技巧：

- 把最容易生成错的内容集中列出。
- 约束要正反结合：必须是什么、绝对不是什么。
- 常见铁律：运动方向、角色身份、造型一致、色卡一致、首尾帧一致、焦段过渡、景别范围、禁止字幕水印、禁止新增人物。

可用写法：

```text
【关键约束】全程一镜到底，无 cuts、无 transitions；起幅严格等于首帧，收幅严格等于尾帧；人物造型不改发型、不改服装、不新增饰品；画面无字幕、无水印、无 UI、无 logo；尾帧不是静止图，衣摆、沙尘、发丝仍持续运动。
```

### 10. 贯穿锚点

描述技巧：

- 贯穿锚点是让整段不散的“连续物理证据”，必须开头声明，中段延续，结尾仍可感知。
- 常见锚点：低频风声、沙粒 hiss、衣摆发丝、手持呼吸微漂、霓虹粉紫色块、冷蓝窗光、化妆间底噪、桌面脏前景、分屏线、色卡。
- 锚点不要只写一次；在动作变化时写它如何跟着变化，例如风声从草浪变成天台高空风、草色漂白成天空、电话底噪随画框转换并入另一空间。

可用写法：

```text
Wind anchor 全段持续：低沙漠风的低频 hum 贯穿，细沙在地表横向拖出流线，人物衣角和发梢始终微动；前 2 秒静默时只有风，动作爆发后风声被脚步和喘息短暂盖住，末帧又回到空旷风声。
```

### 11. Camera Operation 摄影机操作感

描述技巧：

- 区分三脚架固定、真人手持、长焦手持、顺滑拉远、桌面高度机位、顶拍、极远反打。
- 手持不是简单“抖动”，要写呼吸漂移、小碰撞、微修正、长焦放大不稳定、绝不等于云台。
- 固定机位要写“画面无运动”，只允许演员、光影、尘埃或前景物运动。
- 从手持转稳定或从固定转拉远时，要写转换节点和原因。

可用写法：

```text
Camera operation：真人手持长焦，画面随操作者呼吸持续轻微漂移，有小幅无意修正和偶发轻碰，永远不是三脚架或云台的绝对稳定；当赛加入画后，相机从手持呼吸感过渡为平滑 dolly back，抖动降低但仍保留实拍重量。
```

### 12. 表演锁定与反差

描述技巧：

- 给每个角色设置表演锁：死pan、零反应、慌乱、从容、滑稽求饶、冷淡执行、慵懒摆烂。
- 反差要成对出现：静止 vs 爆发、冷淡 vs 狂躁、低调阴影 vs 明亮对称、极小剪影 vs 突然剧烈动作。
- 表演锁不仅写表情，也写身体：呼吸、肩膀、头部转动、重心、手脚、台词速度。

可用写法：

```text
Character performance lock：甲全程零反应，身体不动，只有极慢头部跟随和微弱呼吸；乙从完全静止瞬间爆成狼狈逃跑，尖叫、手脚并用、摔倒、爬起，动作越慌乱越凸显甲的冷淡。
```

### 13. 画框转换 / 分屏

描述技巧：

- 先写原始画面，再写分割线方向、移动路径、替换区域、最终画幅比例。
- 左右或上下分屏必须各自定义机位、色调、亮度、底噪和角色动作。
- 画框转换要有声音：轻微 hum、旧空间底噪保留、新空间底噪进入、台词从电话或画外进入。
- 转换后不要让两个空间的风格混在一起；一侧可以王家卫暗调霓虹，另一侧可以韦斯安德森明亮对称。

可用写法：

```text
【画框转换】台词尾音后约半秒，竖直分割线从右边缘向中央移动；经过区域被另一个空间替换，原画面被压缩成左半边方形，最终形成左右 8:9 对称分屏。左侧保留冷蓝波光和化妆间底噪，右侧进入米白床面、对称顶拍和采耳店室内低频。
```

### 14. 遮挡调度

描述技巧：

- 遮挡物必须在前景，写占画面比例、位置、清晰度、朝向镜头。
- 写清被遮挡对象在后景哪里，只露出哪些边缘：肩膀、头顶、衣角、手臂一点点。
- 遮挡要承担功能：保护画面、制造喜剧、引导视线、强调道具主体。
- 如果涉及换衣、受伤、惊吓等容易误生成的动作，必须用遮挡物和禁止项双重锁定。

可用写法：

```text
牛公仔放到桌面前景左侧，正脸朝镜头，清晰锐利，占画幅一半以上；后景人物位于公仔正后方，具体动作 100% 被公仔挡住，只能从左右边缘看到一点肩膀和头部上沿，绝不出现无遮挡的后景动作。
```

### 15. 打斗与动作喜剧节拍

描述技巧：

- 打斗不是招式堆叠，要按节拍写：静止对峙 → 起手 → 第一击 → 格挡/闪避 → 失衡/撞击 → 反应停顿 → 反击 → 收束。
- 每一下动作都写身体力线、道具轨迹、环境反馈和声音：脚踩碎瓦、刀背擦过柱子、衣摆被风抽直、木桌震动。
- 喜剧动作要写“静默停顿”和“突变”：先僵住，再突然弹起、摔倒、爬起、求饶或被吞声切断。
- 不需要血腥；重点写力、速度、失衡、表情和声音。

可用写法：

```text
0-2秒：两人静止对峙，只有雨滴和呼吸。2秒整，甲突然低身冲出，刀鞘贴地扫过积水，水花横向炸开；乙后撤半步用伞骨格挡，伞面被震得向后凹陷，竹柄发出短促裂响。3-5秒，甲借反弹旋身，衣摆抽出一道湿冷弧线，乙被逼到柱旁，肩膀撞柱，灰尘落下。
```

### 16. 切镜对话节拍

描述技巧：

- 对话不是台词列表，要写镜头逻辑：建立空间、A 说话、B 反应、插入物件、A 再压迫、B 微表情变化、收尾定格。
- 每句台词绑定动作和声音：音色、语速、音量、是否电话声、是否画外小声。
- 切镜要写景别变化：过肩、正反打、特写、插入镜头、反应镜头。
- 保留停顿：台词尾音后半秒、环境声下沉、眼神移动、呼吸卡住。

可用写法：

```text
HARD CUT 到乙脸部特写，背景彻底虚化；乙先低头看一眼桌上的旧钥匙，再抬眼看向画面左前方，声音压低说：“你昨天来过。” HARD CUT 插入钥匙特写，钥匙边缘还沾着雨水，空调低频压住半秒静默。HARD CUT 回甲过肩，甲没有马上回答，只用拇指擦掉钥匙上的水，停半拍后说：“我只是路过。”
```

### A. 无场景图风格描述类型

```text
【中段过渡阶段】镜头如何移动、主体如何变化、空间关系如何推进、动作如何完成。
```

完整范例：

```text

[STYLE LOCK]

[REFERENCE LOCK]
@图片1 作为反派骑手视觉锚定：独眼、短乱发、深红围巾、赤膊纹身、右臂青铜义肢、背挂弯刀，造型不改。
@图片2 作为机械坐骑视觉锚定：四条机械腿、青铜装甲、单只青色发光眼、双角塔尖，体型接近战马。
@图片3 作为逃跑沙舟视觉锚定：木质船身、铜绿机械腿、红色船腹、尾部破布旗。
@图片4 作为色卡锚定：暖沙金、赭红、铜绿、深黑阴影、青色发光缝隙严格保持。
@音频1 作为反派音色锚定：低沉沙哑、短促、带压迫感，不喊叫。

【场景物理设置】
所有运动主体朝画面深处同一方向狂奔，不存在对冲。逃跑沙舟在最前方，两个小沙艇在中间追击，反派骑机械坐骑从最后方加速追上。沙舟虽然被追但始终高速奔跑，九条机械腿持续踏沙；机械坐骑速度最快，从小沙艇后方追平并超越到小沙艇前方。

【起手阶段】0-3秒
24mm 低机位贴近沙地，镜头在机械坐骑后方略偏侧，前景下半部被坐骑后蹄和扬起的沙浪占据；反派身体前倾骑在坐骑背上，深红围巾被风向后抽直。远景里 @图片3 沙舟体积很小但仍能看见机械腿踏沙，两个小沙艇在沙舟与坐骑之间扬尘追逐。声音是高速风声、机械蹄落沙、沙舟远处闷重脚步和小沙艇引擎。

【中段过渡阶段】3-9秒
真人手持追拍，镜头从贴地后方逐步抬升到反派侧前方中近景，焦段从广角强透视平滑过渡到接近标准镜头。机械坐骑追平第一个小沙艇，沙艇从画面中景滑向反派身后；反派不急不吼，只微微低头看向远处沙舟，嘴角几乎不可见地上扬。沙尘一直横向拖尾，色卡里的暖沙金和铜绿在逆光里闪烁。反派用 @音频1 的低哑音色短促说：“追上了。”

【收手阶段】9-12秒
```

## 提示词细化口诀

- 先锁风格，再锁参考，再锁空间。
- 先写方向，再写速度，再写动作。
- 先写起幅，再写过渡，再写收幅。
- 先写画面，再写声音，再写约束。
- 先描述参考图内容，再声明参考图用途。
- 风格引用必须翻译成镜头、光线、色彩、剪辑、材质。
- 每个小标题都要回答“它控制模型的哪一类错误”。
- 每段都要有一个持续锚点，让模型知道“这还是同一个镜头/同一段戏”。
- 对话要写镜头切换和声音空间，不只写谁说什么。
- 动作要写失衡、撞击、停顿和收束，不只写招式名。
