# 情绪导演参考

用于 MX Shell Prompt 中的情绪描写转译。只有素材包含情绪状态、内心变化、哭喊、恐惧、愤怒、羞耻、犹豫、崩溃、爱恋、压抑、麻木、紧张对峙等内容时读取。

## 核心原则

禁止把情绪直接写成抽象标签。必须转成可拍摄、可表演、可听见的物理表现。

禁止：

- 他很害怕。
- 她心碎了。
- 他杀气腾腾。
- 她绝望如深渊。

改成：

- 他瞳孔明显扩大，眼白露出更多，胸口快速起伏，手指轻微颤抖，身体向后缩。
- 她嘴角下拉，肩膀向内收，眼眶湿润反光，呼吸被压在喉咙里。
- 他下颌咬紧，视线固定在对方脸上，肩膀向前顶，拳头握到指节发白。
- 她瞳孔失焦，头垂下，双手垂在身侧，膝盖发软。

对白、旁白、画外音可以保留原句；但说话方式必须写成声音行为。

## 情绪转译表

| 情绪 | 可拍表现 |
|---|---|
| 恐惧 | 瞳孔扩大，眼白增多，胸口快速起伏，手指颤抖，身体后缩，重心不稳 |
| 愤怒 | 下颌肌肉隆起，鼻孔扩张，呼气粗重，拳头握紧，肩膀向前顶 |
| 羞耻 | 视线下移，脖颈僵住，嘴唇抿紧，手指抓住衣角或裤缝，肩膀收窄 |
| 犹豫 | 手伸出后停住，视线在目标和出口之间来回，脚尖转向又收回 |
| 悲伤 | 眼睑下垂，下眼睑湿润，嘴角下拉，肩膀内收，头低到胸前 |
| 崩溃 | 呼吸断开，肩膀抽动，手臂失去支撑，膝盖弯曲，声音破裂 |
| 决绝 | 下颌前顶，眼神固定，嘴唇抿成线，动作变慢但更用力 |
| 麻木 | 面部松弛，不眨眼或眨眼间隔变长，身体长时间静止，胸口起伏变小 |
| 仇恨 | 眼神盯住目标，嘴角下压，呼吸变稳，动作变精准，没有多余动作 |
| 爱恋 | 视线缓慢扫过对方面部，眼睑低垂，嘴角轻微上扬，身体不自觉靠近 |
| 震惊 | 身体瞬间僵住，嘴巴微张，瞳孔收缩，长时间不眨眼 |

## 情绪曲线

为每个情绪场景建立曲线：

```text
起点 → 过渡 → 峰值 → 回落/转化
```

例：

```text
压抑 → 愤怒 → 爆发 → 短暂失控 → 空洞
```

相邻阶段必须有过渡，不能突然跳变。

## 动作设计

每个关键动作写清：

- 起点：身体或道具从哪里开始。
- 过程：如何移动，速度是缓慢、加速、骤停、爆发还是控制。
- 终点：动作停在哪里，产生什么结果。
- 反馈：环境或道具如何响应。

动作层次：

- 微动作：手指抽动、嘴角颤动、脚尖轻点。
- 惯性动作：搓手指、摸耳垂、反复握拳松开。
- 神经反应：吞咽、喉结滚动、瞳孔震动、重心瞬间失衡。
- 失控反应：肩膀剧烈抖动、膝盖发软、牙齿打颤、身体前后摇晃。

## 声音设计

台词必须标注音量、音质、语速和停顿。

可用标签：

- （气音）
- （低声）
- （声音发抖）
- （声音劈裂）
- （断断续续）
- （嘶喊）
- （唇动无声）

哭声不要直接写“哭”。写形成过程：

```text
鼻腔先堵住，吸气变短，肩膀开始抽动，声音从喉咙里断开。
```

笑声不要直接写“哈哈”。写形成过程：

```text
他先短促吸气，鼻腔挤出一声笑，随后嘴角扩大，肩膀开始抖。
```

## 环境反馈

角色动作必须影响环境：

- 纸币被攥皱。
- 烟灰掉到手背。
- 酒杯震出水线。
- 门框被抓出木屑。
- 玻璃因撞击震动或碎裂。
- 水龙头声盖住呼吸。
- 衣料被抓紧发出摩擦声。

反馈必须与动作同步，不要先写结果再补原因。

## 禁用写法

- 不用文学化比喻、拟人、象征。
- 不用精确毫米、厘米、角度、小数比例。
- 不写“内心想起/意识到/感到”，除非转成可见动作。
- 不让角色长时间静止；静止也要写呼吸、眨眼、喉结或手指变化。

## 输出提醒

情绪导演不是额外段落，而是写进 MX Shell 的【画面内容】里。必要时在【声音】里强化呼吸、哭声、破音和环境声。
