# MX Shell Prompt — 脚本转结构化视频提示词

把故事大纲、剧本片段、分镜草稿、小说段落、口播文案或一句粗略想法，转成可直接复制到 Seedance 2.0 / Kling / 即梦 等工具的 MX-Shell 结构化视频提示词。

核心理念：

1. 一个板块 = 一次生成单元。按场景、时间、情绪转折和主体视角切分。
2. 每个板块必须包含：基础设定、氛围与画质、声音、画面内容。
3. 有情绪描写时，必须进入“情绪导演”流程，把抽象情绪转成可见的身体、声音、动作和环境反馈。

## 需要读取的参考

- 结构模板：`references/template.md`
- 摄影与影调词库：`references/cinematic-vocabulary.md`
- 景别/构图/运镜：`references/shot-catalog.md`
- Seedance 细化提示词分类、问答重构、画框转换、动作喜剧、打斗与对话反推规则：`references/prompt-taxonomy.md`
- 情绪导演：`references/emotion-director.md`

只在需要时读取对应参考。遇到“Seedance、即梦、参考图、首尾帧、关键帧、长镜头、固定镜头、蒙太奇、分屏、画框转换、转场、打斗、动作喜剧、遮挡调度、风格复刻、画面细节、电视大师、电影大师、运镜风格、提示词类型、参考文档反推、问答模式、我不满意、重新问我、逐项提问”等内容时，必须读取 `prompt-taxonomy.md`。遇到“害怕、愤怒、羞耻、崩溃、哭、犹豫、压抑、爱恋、麻木、紧张、内心变化、情绪曲线、表演细节”等内容时，必须读取 `emotion-director.md`。

## 工作流程

### Step -1：强制类型判断与完整结构契约

每次生成提示词前，必须先完成以下动作，不允许直接写正文：

1. 完整读取本 `SKILL.md`，再按任务读取所需参考文件；不要只凭记忆或只看 metadata。
2. 先判断提示词类型，再决定结构。常用类型与必备结构如下：
   - 一镜到底 / 长镜头：`[STYLE LOCK]`、`[REFERENCE LOCK]`、起幅、收幅、连续运镜、画面内容、尾帧动态保持、关键约束。
   - HARD CUT 硬切蒙太奇：`[STYLE LOCK]`、`[REFERENCE LOCK]`、场景空间规则、每个 HARD CUT 的独立机位/构图/动作/音效、关键约束。
   - 多机位剧情 / 正反打对话：`[STYLE LOCK]`、`[REFERENCE LOCK]`、场景空间规则、画面构图与镜头、音效/对白归属、正反打分镜、收束、关键约束。
   - 固定镜头 / 关键帧 / 图像提示词：用途、`[STYLE LOCK]`、`[REFERENCE LOCK]`、镜头与机位、构图、光线、空间关系、材质细节、约束。
   - 画框转换 / 分屏对话：`[STYLE LOCK]`、`[REFERENCE LOCK]`、原始空间、画框转换机制、左右/上下空间、声音归属、回到单画面或尾帧、约束。
   - 打斗 / 动作喜剧：`[STYLE LOCK]`、`[REFERENCE LOCK]`、场景物理、摄影机操作、动作节拍、表演锁、音效设计、关键约束。
3. 读取参考文件规则：
   - 生成任何完整提示词时，必须读取 `references/template.md` 和 `references/prompt-taxonomy.md`。
   - 涉及镜头、景别、构图、HARD CUT、一镜到底、正反打、运镜时，必须读取 `references/shot-catalog.md`。
   - 涉及影调、色彩、摄影机、胶片、灯光、质感时，必须读取 `references/cinematic-vocabulary.md`。
   - 涉及情绪、暧昧、爱恋、紧张、害羞、犹豫、崩溃、恐惧、愤怒、内心变化或表演细节时，必须读取 `references/emotion-director.md`。
   - 用户提供“参考提示词 / 参考模板 / txt 文件”时，必须读取这些文件，并模仿其精细度、段落密度、锁定方式、镜头语法、音效层级和约束强度；不要照搬无关题材。

#### 最终输出必备格式

最终提示词不能只是剧情摘要。除非用户明确要求极简版，否则至少包含这些块：

```text
Plan：
[输入判断、提示词类型、结构、参考材料用途、风格/运镜依据、贯穿锚点、风险点]

[STYLE LOCK]
[摄影机、镜头、胶片/质感、光线、色调、画幅、真实感等级、风格禁项]

[REFERENCE LOCK]
[先描述每个参考内容，再说明锁定用途：人物/服装/场景/道具/色卡/构图/首帧/尾帧/声音]

【基础设定】
[时长、连续性、剧情目标、人物关系、关键动作、禁止跑偏]

【场景空间规则】
[空间布局、前景/中景/背景、人物位置、道具位置、物理连续性]

【画面构图与镜头】
[景别、焦段、机位高度、焦点平面、遮挡关系、构图占比、运镜或切镜节奏]

【音效】
[无 BGM 除非用户指定、环境底噪、动作音、对白声音行为、话筒/广播/电话/回声归属]

【画面内容】
[一镜到底动作链，或 HARD CUT / 正反打分镜；每段写景别、构图、动作起点-过程-终点、表演、道具交互、环境反馈]

【收束 / 衔接点】
[精确尾帧状态、动态保持、下一段衔接]

【关键约束 / 禁止】
[集中列出可验证禁项，删除互相冲突的约束]
```

#### 输出前自查

发送最终答案前，必须检查：

- 已写明提示词类型，且结构匹配该类型。
- `[STYLE LOCK]` 不是空泛风格词，包含可执行的镜头、光线、色彩、胶片/质感与风格禁项。
- `[REFERENCE LOCK]` 先描述参考，再说明锁定用途；没有只写“参考 @图片N”。
- 场景空间清楚：布局、前中后景、人物位置、道具位置、物理连续性。
- 镜头清楚：景别、焦段、机位、焦点、遮挡、构图、运镜或切镜节奏。
- 【音效】独立成段：环境声、动作声、对白/话筒/广播/回声归属清楚。
- 情绪已转译为眼神、嘴角、呼吸、肩膀、手指、重心、声音行为和环境反馈。
- 对白绑定动作和声音行为，不只是台词列表。
- HARD CUT 每段都有独立机位、构图、动作、声音和切镜逻辑。
- 一镜到底有起幅、连续运镜、动作链、收幅和尾帧动态保持。
- 约束集中、可验证、无冲突。
- 如果用户提供参考提示词文件，最终精细度必须接近参考文件，不得明显简化。

### Step 0：先 Plan 提示词结构

每次生成 Seedance / 即梦提示词前，先做一个简短 plan，不直接进入正文。Plan 必须说明：

- 输入类型：纯剧情、参考图、参考视频、首尾帧、关键帧、图像提示词、长镜头、固定镜头、蒙太奇或混合素材。
- 采用的提示词类型：从 `prompt-taxonomy.md` 的三类中选择，必要时组合使用。
- 结构：本次输出包含哪些锁定块、画面段落、声音段落、约束段落。
- 参考图内容：若用户提供参考图或文字描述图，先概括画面主体、场景、色调、构图、可继承元素、不可改动元素。
- 风格与运镜依据：选择 1-2 个导演/摄影参考，并说明只引用其技术特点，不泛泛堆砌名字。
- 贯穿锚点：说明本段是否需要风、尘、水汽、噪声、手持呼吸、分屏线、遮挡物、色卡、动作节拍等持续存在的锚点。

短需求可以把 plan 压缩成 3-5 行；复杂剧情或多参考素材必须先列出分段和每段生成目标。

### Step 0.5：审阅不满意时进入问答重构模式

当用户审阅后表示“不满意、使用问答模式、你问我、逐项问、先别生成”等意思时，不要立刻重写完整提示词。必须执行：

1. 读取 `references/prompt-taxonomy.md` 的“问答重构模式”。
2. 先复盘已有提示词，列出：已确定信息、缺失信息、最可能导致不满意的模块。
3. 按提示词类型选择问题模块：镜头与机位、场景物理、参考锁定、动作/表演、特效/转场、声音、约束。
4. 每轮只问 3-6 个高价值问题。每个问题给 3-5 个建议选项，并允许用户自由补充。
5. 用户回答后，把答案写入“已确认设定”，继续问下一组缺失模块；当关键模块足够完整时，再生成完整提示词。
6. 最终生成前做目标对比：保留服务目标的答案，删除空泛或互相冲突的描述。

问答模式的问题必须来自已有提示词和模板反推，不要问泛泛的“你想要什么风格”。例如要问“这是固定顶拍、手持长焦反打、低机位追拍，还是首尾帧连续转场？”、“场景里哪个物体必须作为贯穿锚点？”、“特效目标是消融重塑、硬切反差、机械变形，还是遮挡隐藏动作？”。

### Step 1：解析脚本并分板块

先把素材拆成板块。切分边界：

- 场景/地点变化。
- 明显时间跳跃。
- 情绪大转折。
- 主体或视角切换。
- 动作段与对话段功能明显不同。

不要过度切分。同一地点的连续动作可以是一个板块，板块内部用多分镜或一镜到底处理。

如果用户给的是长脚本，先输出分段概览让用户确认：

```text
我把脚本拆成 N 个板块：
板块一：[一句话摘要]
板块二：[一句话摘要]
确认这个分段吗？要合并/拆开某块直接说。（说“直接写”我就按这个展开）
```

如果用户明确要求“直接生成”或输入很短，可以直接展开。

### Step 2：选择模式

优先遵循用户指定：

- 一镜到底：单一连续动作、情绪流、空间巡游、沉浸式氛围。
- 多机位分镜：动作多、角色多、信息切换多、情绪转折明显。
- 固定镜头/关键帧：单帧构图、首帧、尾帧、截图锚定、图像生成提示词。
- 首尾帧长镜头：有明确起幅/收幅，要求中间连续运镜、动作过渡和尾帧锁定。
- 硬切蒙太奇：多地点、多时间、多光影段落快速拼接，每段独立机位，靠剪辑节奏而非连续运镜连接。
- 画框转换/分屏对话：电话、远程对话、双空间并置、竖线/横线切换、左右画面不同风格。
- Jump cut 前后反差：前段短、后段长，前后景别/状态突然变化，用喜剧或惊吓节奏制造落差。

用户未指定时自动判断。对暴力、追逐、对峙、群体冲突，默认多机位分镜；对独处、情绪压抑、空间探索，默认一镜到底或慢分镜。

### Step 3：生成每个板块的四大区块

输出顺序固定：

```text
【基础设定】
【氛围与画质】
【声音】
【画面内容】
```

基础设定必须包含角色、关键道具和场景。若有参考图，每个元素用 `{{Portrait N}}` 或用户指定的引用，描述压缩到20字左右；若无参考图，写清外形、服装、标志、材质、状态、时代感。

氛围与画质必须包含：

- 风格核心：1-2个主风格 + 情绪关键词 + 电影级质感、超写实、真人实景拍摄、杜绝游戏CG感。
- 视觉基调：摄影机 + 镜头 + 拍摄方式 + 动态模糊/手持抖动等。
- 色彩与影调：主色、辅色、饱和度、对比度、光源方向、胶片质感、画幅。

声音默认：

```text
声音规则：不需要配乐，仅保留同期声。
对白与画外音处理：保留素材中原有角色对白、旁白、画外音；不添加素材中未指定的额外音轨；禁止字幕叠加。
```

有对白时，必须把台词绑定到动作节拍：

```text
角色名 + 情绪标签 + 关联动作 + 说：“台词”
```

### Step 4：画面内容写法

每个镜头必须包含：

- 时间段：如 `0-3秒`。
- 景别：特写、中近景、中景、全景等，并说明拍哪里。
- 构图：主体位置、前景/中景/背景、视觉重心。
- 运镜手法：固定、推进、跟踪、手持、摇臂、甩镜、移焦等。
- 动作描述：角色动作、道具交互、表情变化、声音、环境反馈。

多机位分镜格式：

```text
分镜1丨0-3秒丨中近景+缓慢推进：
[动作描述；如含对白，嵌入：角色+情绪标签+关联动作+说：“台词”]
```

一镜到底格式：

```text
分镜：单镜头一镜到底。
景别：[起始景别，说明变化]
构图：[前景/背景/画面占比/方位关系]
运镜手法：[镜头运动路径]
画面内容：
0-3秒：[动作链]
3-7秒：[动作链]
7-12秒：[动作链]
```

## 情绪导演规则

当素材中出现情绪描写，不要只写“他很害怕/她很愤怒”。读取 `references/emotion-director.md`，并执行：

1. 提取情绪曲线：起点 → 过渡 → 峰值 → 回落/转化。
2. 把每个情绪词转成生理表现：眼睛、下颌、嘴唇、呼吸、喉结、肩膀、手指、膝盖、重心。
3. 把情绪转成动作链：起点 → 过程 → 终点。
4. 把台词转成声音行为：音量、音质、语速、停顿、破音、气音、嘶喊。
5. 加入环境反馈：纸币被攥皱、水面震动、玻璃颤动、衣料摩擦、门框响动等。

禁止文学化修辞。对白、旁白、画外音可以保留原句；提示词中的动作与情绪解释必须是可拍、可见、可听的物理表现。

## 写作原则

- 视觉要具体：写光源位置、颜色、反光、阴影、人物所在位置。
- 动作要有起点、过程、终点。
- 情绪必须落到身体和声音。
- 道具必须写状态和剧情关系。
- 负面指令集中放在“氛围与画质”，不要散落到每个镜头。
- 不用毫米、厘米、角度、小数比例等精确物理数值；用“一臂距离、近到看清睫毛、人物占画面一半、低角度、半明半暗”等相对描述。
- 不添加用户未要求的配乐、字幕、logo、水印。
- 保持跨板块一致性：角色、服装、画幅和整体风格在板块一定义，后续只写变化。
- 风格引用必须写成“可执行的摄影/美术/剪辑特点”：例如王家卫=35mm胶片、手持、慢门拖影、霓虹/钨丝灯混色、硬切生活片段；乔治·米勒=低机位高速追拍、同向运动铁律、强透视、沙尘逆光、动作因果清晰；维伦纽瓦=巨物压迫、低饱和沙土色、宏大留白、慢速推进。不要只写导演名字。
- 参考图/参考视频必须先描述再引用：说明它锁定人物、道具、场景、色卡、构图、首帧、尾帧、动作、运镜还是声音。不要只写“参考 @图片1”。
- 场景描述要拆成空间、光线、材质、天气/空气、前中后景、运动方向、声音来源，不只写“沙漠/房间/夜市”。
- 约束要可验证：把运动方向、主体身份、焦段变化、首尾帧姿态、禁止项集中写成“铁律/约束”，避免散落在正文里。
- 先写贯穿锚点：例如全段持续低沙漠风、手持呼吸感、霓虹粉紫色块、化妆间底噪、桌面前景遮挡。锚点要在每个段落里自然延续。
- 表演要写反差：一个角色死pan、另一个角色慌乱；一个空间低调阴影，另一个空间明亮对称；一个动作疯狂，另一个人物无反应。
- 对话场景要写听觉层级：电话声、画外小声、角色正声、环境底噪、过场 hum，各自音量和空间归属不同。
- 遮挡调度要写清“遮挡物挡住什么”：遮挡物占比、位置、清晰度、后景人物只露哪些边缘，避免模型露出不该露出的动作或画面。

## 常见错误

- 分段失当：一个板块塞两个不相关场景。
- 漏道具：枪、纸币、香烟、酒瓶等关键物件没有单列状态。
- 情绪只写标签：没有身体表现。
- 对白悬空：台词没有绑定说话动作。
- 运镜与情绪不匹配：压抑场景用过度甩镜，动作场景用静态长镜头。
- 风格堆砌：同时引用过多风格。
- 贯穿锚点丢失：开头写了风、尘、手持呼吸或分屏线，中段没有继续维持。
- 遮挡关系不明确：只写“挡住”，没有写遮挡物位置、占比、前后层级。
- 对话声音混成一层：电话、画外小声、现场声没有区分音量与空间来源。

## 质量检查

输出前检查：

- 已先输出或内部完成提示词结构 plan：输入类型、提示词类型、结构、参考内容、风格与运镜依据清楚。
- 涉及 Seedance / 即梦 / 参考图 / 首尾帧 / 关键帧时，已读取 `references/prompt-taxonomy.md` 并选择对应类型。
- 已按场景/时间/情绪节拍分板块。
- 已明确一镜到底或多机位分镜。
- 每个板块有基础设定、氛围与画质、声音、画面内容。
- 有参考图时使用 `{{Portrait N}}` 或用户指定引用；无参考图时写具体物理外观。
- 参考图/视频已先描述内容，再声明锁定用途；没有只写“参考 @图片N”。
- 风格/导演/摄影师引用已转成可执行的镜头、光线、色彩、剪辑、材质特点。
- 已设置并延续贯穿锚点：风/尘/水汽/手持呼吸/底噪/分屏线/遮挡物/色卡等。
- 打斗或动作喜剧已写清节拍：起手、突变、摔倒/反击/格挡、停顿、收束，不只写“打起来”。
- 切镜对话或分屏对话已写清画框转换、双方机位、声音归属、台词节拍和反应镜头。
- 有情绪描写时已读取 `references/emotion-director.md` 并转成身体、声音、动作和环境反馈。
- 每个分镜有时间段、景别、构图、运镜、动作内容。
- 对白/旁白保留原意，绑定动作节拍。
- 没有文学化修辞、现代错位元素、字幕、水印、logo。
